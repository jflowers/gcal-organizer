# Data Model: macOS Signed Releases

**Feature**: 010-macos-signed-releases
**Date**: 2026-03-08

This feature has no traditional database entities. The "data model" consists of CI/CD configuration files, release artifacts with lifecycle states, and credential schemas.

## Entity: GoReleaser Configuration

**File**: `.goreleaser.yaml` (repository root)
**Format**: YAML (GoReleaser v2 schema)

| Field | Type | Purpose |
|-------|------|---------|
| `version` | integer | Schema version. Fixed at `2`. |
| `builds[].main` | string | Go main package path. `./cmd/gcal-organizer`. |
| `builds[].binary` | string | Output binary name. `gcal-organizer`. |
| `builds[].env` | list | Build environment. `CGO_ENABLED=0`. |
| `builds[].goos` | list | Target operating systems. `[darwin, linux]`. |
| `builds[].goarch` | list | Target architectures. `[amd64, arm64]`. |
| `builds[].ldflags` | list | Linker flags. Injects `-X main.Version={{.Tag}}`. |
| `archives[].formats` | list | Archive format. `[tar.gz]`. |
| `archives[].name_template` | string | Archive naming. `gcal-organizer_{{ .Version }}_{{ .Os }}_{{ .Arch }}`. |
| `archives[].files` | list | Extra files in archive. `[LICENSE*, man/gcal-organizer.1]`. |
| `checksum.name_template` | string | Checksums filename. `checksums.txt`. |
| `homebrew_casks[].name` | string | Cask name. `gcal-organizer`. |
| `homebrew_casks[].directory` | string | Directory in tap repo. `Casks`. |
| `homebrew_casks[].repository` | object | Tap repo coordinates. `{owner: jflowers, name: homebrew-gcal-organizer}`. |
| `homebrew_casks[].binaries` | list | Binaries to install from archive. `[gcal-organizer]`. |
| `homebrew_casks[].manpages` | list | Man pages to install from archive. `[man/gcal-organizer.1]`. |

## Entity: Release Archive

**Naming**: `gcal-organizer_<version>_<os>_<arch>.tar.gz`
**Contents**: Binary (`gcal-organizer`) + man page (`man/gcal-organizer.1`) + LICENSE

### Lifecycle States

```
┌──────────┐     GoReleaser      ┌──────────┐    sign-macos job    ┌────────┐
│  Source   │ ──────────────────► │ Unsigned │ ─────────────────► │ Signed │
│  (Go)    │     build+archive   │ (GitHub  │   codesign+notarize │(GitHub │
│          │                     │  Release)│   replace+clobber   │Release)│
└──────────┘                     └──────────┘                     └────────┘
                                       │                               │
                                       └── Linux archives ────────────►│
                                           (unchanged, no signing)     │
```

| State | Applies To | Description |
|-------|-----------|-------------|
| Unsigned | All archives | Initial state after GoReleaser build. Published to GitHub Release. |
| Signed | darwin archives only | macOS binary code-signed and notarized. Replaces unsigned archive in GitHub Release. Linux archives remain unsigned (no macOS signing needed). |

### Validation Rules

- Archive name MUST match pattern: `gcal-organizer_<semver>_<os>_<arch>.tar.gz`
- `<os>` MUST be one of: `darwin`, `linux`
- `<arch>` MUST be one of: `amd64`, `arm64`
- Archive MUST contain exactly one binary named `gcal-organizer`
- Archive MUST contain `man/gcal-organizer.1`
- Signed darwin binaries MUST pass `codesign --verify --verbose=2`
- Signed darwin binaries MUST be accepted by Apple's notarization service

## Entity: Checksums File

**File**: `checksums.txt` (release asset)
**Format**: One line per archive: `<sha256_hex>  <archive_filename>`

### Lifecycle States

```
┌──────────┐   GoReleaser    ┌──────────────┐   sign-macos    ┌─────────────┐
│  (none)  │ ──────────────► │ All unsigned │ ──────────────► │ Mixed       │
│          │   checksum gen  │ checksums    │  strip darwin   │ (linux:orig │
│          │                 │              │  recompute      │  darwin:new) │
└──────────┘                 └──────────────┘                 └─────────────┘
```

| State | Description |
|-------|-------------|
| All unsigned | Generated by GoReleaser. SHA256 hashes for all 4 unsigned archives. |
| Mixed | After signing: linux checksums preserved from original, darwin checksums recomputed from signed archives. |

### Validation Rules

- Each line MUST match format: `<64-char-hex>  <filename>`
- Every archive in the release MUST have exactly one corresponding checksum line
- No duplicate filenames
- SHA256 MUST match actual file content (verifiable with `shasum -a 256`)

## Entity: Signing Credential Set

**Storage**: GitHub repository secrets (never in source code)

| Secret Name | Content | Encoding | Source |
|-------------|---------|----------|--------|
| `MACOS_SIGN_P12` | Developer ID Application certificate + private key | Base64 | Exported from macOS Keychain Access as `.p12` |
| `MACOS_SIGN_PASSWORD` | Password protecting the `.p12` file | Plain text | Set during `.p12` export |
| `MACOS_NOTARY_KEY` | App Store Connect API key | Base64 | Downloaded from App Store Connect as `.p8` |
| `MACOS_NOTARY_KEY_ID` | API key identifier | Plain text | Shown in App Store Connect > Users and Access > Integrations |
| `MACOS_NOTARY_ISSUER_ID` | API issuer UUID | Plain text | Shown in App Store Connect > Users and Access > Integrations |

### Temporary Artifacts (ephemeral, per-job)

| Artifact | Path | Lifecycle |
|----------|------|-----------|
| `cert.p12` | `$RUNNER_TEMP/cert.p12` | Decoded from `MACOS_SIGN_P12`. Imported into temporary keychain. Destroyed when runner is recycled. |
| `app-signing.keychain-db` | `$RUNNER_TEMP/app-signing.keychain-db` | Temporary keychain. Random password. Destroyed when runner is recycled. |
| `notary_key.p8` | `$RUNNER_TEMP/notary_key.p8` | Decoded from `MACOS_NOTARY_KEY`. Used for notarytool authentication. Destroyed when runner is recycled. |

## Entity: Homebrew Cask

**File**: `Casks/gcal-organizer.rb` (in tap repository `jflowers/homebrew-gcal-organizer`)
**Format**: Ruby DSL (Homebrew Cask format)

### Structure

```ruby
cask "gcal-organizer" do
  name "gcal-organizer"
  desc "Automate meeting note organization, calendar syncing, and task assignment"
  homepage "https://github.com/jflowers/gcal-organizer"
  version "<release_version>"

  binary "gcal-organizer"
  manpage "man/gcal-organizer.1"

  on_macos do
    on_intel do
      url "https://github.com/jflowers/gcal-organizer/releases/download/v#{version}/gcal-organizer_#{version}_darwin_amd64.tar.gz"
      sha256 "<sha256_of_signed_amd64_archive>"
    end
    on_arm do
      url "https://github.com/jflowers/gcal-organizer/releases/download/v#{version}/gcal-organizer_#{version}_darwin_arm64.tar.gz"
      sha256 "<sha256_of_signed_arm64_archive>"
    end
  end

  on_linux do
    on_intel do
      url "https://github.com/jflowers/gcal-organizer/releases/download/v#{version}/gcal-organizer_#{version}_linux_amd64.tar.gz"
      sha256 "<sha256_of_linux_amd64_archive>"
    end
    on_arm do
      url "https://github.com/jflowers/gcal-organizer/releases/download/v#{version}/gcal-organizer_#{version}_linux_arm64.tar.gz"
      sha256 "<sha256_of_linux_arm64_archive>"
    end
  end
end
```

### Lifecycle States

```
┌──────────┐  GoReleaser push   ┌──────────────┐  sign-macos push   ┌──────────────┐
│  (none)  │ ────────────────► │ Unsigned     │ ──────────────────► │ Signed       │
│          │                   │ checksums    │   update darwin     │ checksums    │
│          │                   │ (all 4 arch) │   sha256 values     │ (mixed)      │
└──────────┘                   └──────────────┘                     └──────────────┘
```

The Cask file receives two commits per release:
1. GoReleaser initial push: `"Brew cask update for gcal-organizer version v<X>"`
2. sign-macos checksum update: `"Update macOS checksums for gcal-organizer v<X> (post-signing)"`

## Workflow Dependency Graph

```
  Tag push (v*)
       │
       ▼
┌─────────────────────────────────────────┐
│  release (ubuntu-latest, 45min)         │
│                                         │
│  1. check-secrets → has_signing_secrets │
│  2. checkout + setup Go                 │
│  3. go test -race ./...                 │
│  4. GoReleaser: build → archive →       │
│     checksum → release → Cask push      │
└─────────────┬───────────────────────────┘
              │
              │ needs: release
              │ if: has_signing_secrets == 'true'
              ▼
┌─────────────────────────────────────────┐
│  sign-macos (macos-latest, 30min)       │
│                                         │
│  1. Import P12 → temporary keychain     │
│  2. Decode P8 notary key                │
│  3. Download darwin archives from       │
│     release                             │
│  4. For each darwin archive:            │
│     extract → codesign → verify →       │
│     zip → notarytool submit --wait →    │
│     re-tar.gz                           │
│  5. Replace release assets (--clobber)  │
│  6. Update checksums.txt                │
│  7. Update Cask checksums in tap repo   │
└─────────────────────────────────────────┘
```
